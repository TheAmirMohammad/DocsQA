# Middleware in FastAPI

A "middleware" is a function that works with every request before it is processed by any specific path operation, and also with every response before returning it.

## Custom Middleware Example

```python
import time
from fastapi import FastAPI, Request

app = FastAPI()

@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    start_time = time.perf_counter()
    response = await call_next(request)
    process_time = time.perf_counter() - start_time
    response.headers["X-Process-Time"] = str(process_time)
    return response
```

### Middleware Lifecycle Execution Order

1. Request received from client network socket.
2. Code before `call_next(request)` is executed (e.g. starting timers, logging IP, inspecting headers).
3. `call_next(request)` passes request to route handlers and dependency injectors.
4. Response generated by the application.
5. Code after `call_next(request)` modifies response (e.g. injecting headers, compressing payload).
6. Response sent to client.
