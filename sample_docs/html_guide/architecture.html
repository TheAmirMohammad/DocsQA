ASGI Architecture and Lifespans

FastAPI is an asynchronous Server Gateway Interface (ASGI) framework designed around asynchronous coroutines and high-concurrency event loops.

Lifespan Context Managers

Manage application startup and shutdown lifecycle using asynccontextmanager instead of deprecated on_event handlers.


@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup: initialize database pool
    yield
    # Shutdown: close connections

Concurrency Model

Endpoints defined with async def run directly on the asyncio event loop. Normal def functions run in an external thread pool to prevent blocking.
